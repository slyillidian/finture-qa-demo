# 换个角色：帮助产品或运营同事（AI 协作撰写，提交者最终审阅）

我会从运营每次活动上线前的“入口链接验收”入手。让同事提供一张清单，写明活动名称、链接、预期页面，以及需要展示的商品或活动编号。AI 可以协助把清单转成工具配置、解释失败报告，并帮助定位信息缺口；确认后的配置交给固定程序重复执行，不让 AI 临场判断测试是否通过。

运营同事需要亲自检查预期是否符合活动方案、登录或资格限制是否合理，以及截图中的价格、时间、文案和视觉展示。自动断言只能证明指定页面和文本出现，无法替他判断活动规则是否正确，也可能遗漏页面布局和素材错误。链接对应的预期应由运营确认，不能直接照抄开发实现，否则容易把同一个错误同时写进程序与测试。

第一次只选三个高频入口，由开发者完成 App 接入，同事负责审阅配置与截图。先记录人工步骤、实际耗时及误报，再决定是否扩大覆盖；报告中的失败是需要排查的线索，不应自动触发上线或下线决策。
