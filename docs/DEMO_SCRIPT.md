## 画面来源与真实性

- 配置章节为 cases/smoke.json 的一条实际用例节选，命令章节展示本次实际执行命令。
- 内部流程页是执行器实现的说明，不冒充终端输出。
- 执行章节将同次模拟器实录与真实 stdout 按采集时间合成显示；上方命令是便于阅读的摘要，设备 ID 在运行面板中略写。不是桌面终端界面录屏，也没有编造 PASS/FAIL。
- 报告章节使用本次 results.json 的字段节选和本次保存的独立 PNG；省略部分字段以便阅读，保持 ui_assertions/checks 等实际结构。报告目录和文件清单显示在页脚。
- 反向用例故意要求 Product 999，实际打开 Product 123；探针通过、UI 失败，退出码 1 为预期。明确标注错误预期演示，不冒充线上事故。
- 执行阶段不加速，前后插入配置、流程、报告等静态说明章节。视频时长不等于纯测试执行耗时。
